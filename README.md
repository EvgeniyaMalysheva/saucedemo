## Тестовое задание «Автоматизация тестирования Java»
### Описание
Автоматизировать тестирование логина на сайте https://www.saucedemo.com/ с использованием Java.
Написать 5 тестов, проверяющих разные сценарии авторизации:
1.	Успешный логин (standard_user / secret_sauce)
2.	Логин с неверным паролем
3.	Логин заблокированного пользователя (locked_out_user)
4.	Логин с пустыми полями
5.	Логин пользователем performance_glitch_user (проверить корректный переход и что страница открывается несмотря на возможные задержки)
### Требования
- Java 17
- Gradle 7.0 или выше
- Браузер (Chrome, Firefox) и соответствующие драйверы (например, Chromedriver)
### Структура проекта:
**src/test/java/tests** – директория с тестами<br>
**src/test/java/data** – для хранения тестовых данных<br>
**src/test/java/utils** – вспомогательные классы и утилиты (получение финального скриншота перед завершением теста, генерация рандомного значения для пароля)<br>
**src/test/java/pages** – реализация паттерна Page Objects Model<br>
**src/test/java/resources** – конфигурационные файлы (логирование Logback)<br>
**build.gradle** — конфигурационный файл сборки и зависимостей<br>
### Установка и запуск
1. Клонирование репозитория
```bash
git clone https://github.com/EvgeniyaMalysheva/saucedemo.git
```
2. Установка зависимостей и сборка проекта
```bash
gradle clean build -x test
```
3. Запуск тестов
```bash
gradle clean test
```
По умолчанию тесты запускаются в браузере Chrome.<br> 
Если требуется запустить тесты в Firefox, нужно использовать команду:
```bash
gradle clean test -Dbrowser=firefox
```
### Формирование отчета:
Для отображения результатов запуска тестов используется Allure Reports.
Для просмотра отчета после окончания тестового прогона необходимо выполнить команду:
```bash
gradle allureServe
```
